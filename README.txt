そばにいる。β v0.37 — 複数キャラ＋長文入力改善

今回の大型アップデート

【長文入力】
・入力した文章に合わせてテキスト欄が自動で伸びる
・スマホでは最大約150pxまで伸び、それ以上は入力欄の中だけスクロール
・キーボード表示中の画面高を visualViewport で追従
・文字入力中もチャット下部を維持しやすく改善
・送信後は入力欄を自動で元の高さへ戻す

【複数キャラクター】
・最大8人
・上部のキャラタブでワンタップ切り替え
・＋で新規キャラ作成
・「この設定を複製」で人格設定をコピーして別キャラ作成
・キャラ削除
・AI名、関係性、性格、話し方、モデル、育成データをキャラ別保存
・会話履歴、固定記憶、思い出、大切な日、共有ノート、気分モードもキャラ別
・アルバム写真もキャラごとに表示
・v0.36までのデータは1人目のキャラとして自動移行

【注意】
・キャラ削除すると、そのキャラの会話や記録も削除されます
・β版では最大8人
・写真は従来どおり端末内IndexedDBに保存

使い方
GitHubの index.html をこのファイルで上書きするだけです。
