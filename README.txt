そばにいる。β v0.36 — ふたりの記録

追加機能
1. 思い出カード
   ・ユーザーのメッセージ下に「⭐ 思い出」
   ・「覚えといて」「覚えてて」でも自動保存
   ・日付つきで保存し、「去年の秋」などの振り返りに利用

2. 大切な日
   ・誕生日、記念日、ライブ、旅行、仕事初日などを登録
   ・毎年繰り返す誕生日・記念日にも対応
   ・「明日ライブ」や「9月12日イベント」など一部は会話から自動登録
   ・30日以内の予定をAIが文脈に応じて覚えて会話

3. ふたりのノート
   ・好きなもの
   ・行きたい場所
   ・食べたいもの
   ・やりたいこと
   ・「行きたい」「食べたい」「やりたい」は短い発言なら自動追加

4. ふたりのアルバム
   ・チャットで送った写真をIndexedDBへ端末内保存
   ・写真＋送った時の一言をアルバム表示
   ・画像自体はlocalStorageには保存しない
   ・端末間の自動同期はありません

5. 今日の会話モード
   ・雑談
   ・甘えたい
   ・静かに話したい
   ・愚痴聞いて
   ・一緒に考えて

その他
・設定を保存した場合は「カスタム人格」扱いになり、
  りゅう人格パックが他人のキャラに勝手に混ざらないよう修正
・v0.35の会話・人格・育成・検索設定を引き継ぎ
・新規ユーザーの呼び名初期値を「あなた」に変更

使い方
GitHubの index.html をこの index.html で上書きするだけ。
