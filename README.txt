追加：Web検索

・「調べて」「検索して」「最新」などを自動検出して本当にWeb検索
・🔎ボタンを押すと、次の1通だけ強制的にWeb検索
・検索はPuterのOpenAI Web Searchを使用
・会話本体はこれまで通りClaude Sonnet 4.6なので、人格は維持
・検索した返答には「🔎 Web検索」バッジを表示
・検索していない時に「今調べてる」と嘘をつかないよう人格指示を追加
・v0.30の人格、記憶、育成、会話を引き継ぎ

注意：
検索するメッセージは「検索用OpenAI」→「会話用Claude」の2回AIを呼ぶので、
通常会話よりPuter側の利用量が少し増えます。

使い方：
1. GitHubの index.html をこのファイルで上書き
2. Puter接続
3. 「大西流星について調べて」などと送る
   または 🔎 を押してから質問する
